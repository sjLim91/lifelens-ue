## 통합 회귀에서 확인한 실제 목표 유실

기존 자연 실패 기억 제거 회귀의 시드 4에서 첫 회복 채집은 재고 1→5였고 원래 목표 8을 달성하지 않았다. 기존 관측기는 첫 회복 토큰의 부분 채집에서 종료했다. 부분 성과를 목표 완료로 만들지 않고, **회복 중인 native 목표도 같은 원래 기한/최대 3회 원천 시도 안에서 추가 실제 채집 또는 실제 생존 행동 후 재개**하도록 연결했다. 원래 일반 native 비회복 채집의 경쟁 판단은 유지한다.

관측기는 첫 실제 회복 토큰과 원래 GoalID의 실제 `achieved` 결과를 모두 요구하며, 90일 자연 관측·시드 4·양수 시작 재고·실패 기억 정확히 한 건만 제거·나머지 snapshot byte 동일·원래 기한·실제 이동·원천 감소·목표 수량 조건을 유지했다. 최종 후보에서 주민 3, 원래 목표/실패 토큰 1369, 기억 유지 회복 토큰 1373, 재고 1→8, 실제 원천 108→101로 전체 목표를 달성했다. 세계·자원·성공 기억을 주입하거나 실패 기준을 낮추지 않았다.

초기 로컬 WASM 대조에서 발견한 로그 차이는 이전에 링크된 native audit 실행기와 변경 후 실행기를 섞어 만든 fixture의 원료 목표/로그 차이였다. 동일한 최신 소스의 native 실행기를 다시 링크해 fixture를 재생성한 뒤 모든 물리/계획/실행 바이트와 기존 난수 텍스트만 정규화한 전체 저장, 중간 저장 재개, 손상 restore의 원자성 검증이 통과했다. 서로 다른 소스의 결과를 표준 라이브러리 차이로 덮지 않았다.

## 현재 생활 판단과 기존 자연 인과 인수

- native 제작 목표가 과거 실험 utility를 현재의 생활 판단보다 높은 전략 우선도로 재사용하지 않도록 했다. 현재 Core 후보 효용으로만 경쟁하고, 수락된 생각의 전략 우선도는 원본 생각이 실제로 존재할 때만 유지한다. native 보유 재료 목표를 모델 목표처럼 좁혀 쓰지 않는다.
- 새 응답은 이미 발행한 물리 토큰의 성공을 취소로 오표기하지 않는다. 낮은 우선도의 새 제안은 실행 중인 실제 작업을 한 번 마치고 실제 결과를 기록한 뒤 이전 목표를 종료한다. 중복 원료 소비가 없음을 통제 Core 회귀로 검증한다.
- 6단계 예산은 기록 개수뿐 아니라 실제 명령 발행에도 적용한다. 네 번의 실제 원천 고갈 실패와 두 번의 1단위 부분 채집으로 예산을 소진하는 통제 회귀에서, 이전 승인으로 발행한 명령은 정확히 6개다. 같은 원래 승인에 따른 일곱 번째 명령과 기한 만료 목표의 재발행을 차단하며, 이후 20분에도 일반 생활 판단은 계속된다. 이 고갈 통제는 무개입 자연 관측으로 계산하지 않는다.
- 실제 실행 이력으로 소진된 승인 예산/기한을 판단하므로 최신 목표가 교체되어도 이전 승인을 되살리지 않는다. 예산 소진 후 140분을 더 진행해 같은 승인 명령 수가 6개임을 확인한다.
- 전체 회귀에서 재료 회복 후 15분 전략 판단 간격 사이에 다른 긴 탐색이 발행되어 원래 제작 기한이 끝나는 단절을 확인했다. 수락된 구체 제작 목표가 열려 있으면 다음 실제 판단 슬롯에서도 동일한 전제조건/생존/사회 안전 게이트를 거쳐 후속 단계를 경쟁시킨다. 모델 생각이 없는 native 생활의 기존 15분 cadence는 유지한다. 기존 통제 실제 경쟁자 고갈 회귀는 첫 실패→원천 B 이동→제작을 원래 기한 안에서 완료하며 인수 조건을 완화하지 않았다.
- 새 계획의 실제 초기 생활 경로 때문에 기존 시드 `4242001`은 14일 안의 완료된 native 성공 기억 원천 대조가 관측되지 않았다. 이 세계를 계속 진단 census에 포함하며 성공으로 바꾸지 않는다. 긍정 인수는 기존 `874213954`와 실제 기회가 있는 독립 시드 `874213955`, `42`의 **세 세계 모두**로 검증한다. 기존 두 세계 최소 조건보다 긍정 인수 세계를 늘렸다. **14일 상한, 주입 없는 New Game, 같은 주민의 두 실제 행동, 정확히 성공 기억 한 건만 제거/재삽입, 나머지 snapshot byte 동일성, 다른 실제 원천 선택과 양쪽의 물리 실행 완료, 중간 저장 재생** 조건은 그대로다. seed/자원/욕구/기억을 바꾸어 특정 장면을 강제하지 않는다. 기본 New Game RNG·출생 생성 방식도 변경하지 않았다.
