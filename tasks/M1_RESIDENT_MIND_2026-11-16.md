# M1 주민 AI 통합 구현·인수

기준 main: `677496c` (#1033). 사용자 요청은 M1-01~07 보완·완료 및 사전 승인된 배포다. 기존 M0/M8/M10, 86개 분모, Core 단일 권위와 Qwen3-1.7B 단일 모델 정책을 유지한다. 과거 사용자 지시대로 물리 기기·발열 검증은 제외하되 소프트웨어 검증을 실제 GPU 추론으로 표시하지 않는다.

## 구현

| 단위 | 실제 제품 경로 |
|---|---|
| M1-01 | `ResidentMind.cpp`의 시각/청각/흔적 `PerceptionFact`. 반경 6칸의 실제 자원·동물·주민, 3칸의 실제 잔류물, 8칸의 실제 활성 화로. Core 나무/바위 경계와 완성된 활성 쉼터로 가림 검사. 가려진 자원은 기존 개인 자원 센서에서도 제외. 보이지 않는 불 소리는 ID/정확한 좌표를 제공하지 않음. |
| M1-02 | 기존 `chooseSingleResidentAgencyDecision` → 동일 `ResidentSensedResourceGoal` → 기존 pending token/production plan 경로 보존. 개인 경험 성향은 이 슬롯의 선택 점수에만 제한적으로 반영. 새 실행기/모델/개인 계획 슬롯 없음. |
| M1-03 | 원래 `MemorySource`·목격 여부·행위자/전언자·시각·위치 보존. 누락되던 `sourceCharacter`를 cognition DTO와 fingerprint에 결속. 감각 관찰은 실행 성공이 아니며 전언·자유 텍스트는 성공/위험/습관 보상을 얻지 않음. |
| M1-04 | 저장된 원래 에피소드 → 출처/대상/영역별 요약 → 검증된 행동 결과의 개인 stance. 최대 24요약/8근거 ID, 12장소. 모든 표시 근거는 원래 저장된 에피소드 fingerprint로 역추적. 표시에서 생략한 근거/에피소드 수를 명시. 중복 요약 저장 테이블을 추가하지 않고 동일 저장본에서 결정론적으로 재구축하며 원래 실행 기억을 요약으로 대체·삭제하지 않음. |
| M1-05 | 장소·자원·위험·동물·사람·도구 영역별 개인 기억/요약, 출처별 장소·시각·신뢰도. 기존 실제 성공 기억 제거 대조와 실제 원천 전환·물리 실행을 함께 검증. 다른 주민에게 경험을 복사하지 않음. |
| M1-06 | 본인의 실제 성공/실패로 호기심·위험 감수·행동 반복 성향을 갱신하고, 같은 위치의 반복 관찰로 애착을 갱신. 실제 상대 행동 결과에서 신뢰 추정. 기본 성격을 덮어쓰지 않고 개인 경험 층을 제공하며 응급 생존을 선점하지 않음. |
| M1-07 | 기존 단일 Qwen worker와 자동 로딩·취소·격리·부재 시 Core 진행을 보존. 대기 중 시효가 지난 입력은 GPU dispatch 전에 거부. Core cognition에는 4요약×4근거/4장소/4감각의 입력 예산을 적용. 실제 신경망 추론과 fake/모델 부재 대조는 별도 기록. |

## 검증과 완료 규칙

- 변경 단위 회귀: `test_resident_mind`, 기존 지각/개인 원천 선택/receipt/affordance 검사, 인지 parser·scheduler 전체 회귀.
- 전체 통합: CMake/CTest, deterministic harness, Web 타입/빌드/회귀, Preflight, 동일 소스의 WASM.
- 장기 감사: `test_resident_mind 1000 SEED`, 1/100/365/1000일의 근거 ID 역추적·지각 기억 상한 48·출처 분리·binary roundtrip·주민별 성향/저장 크기. 멸종/질병/학습 부재도 그대로 기록.
- Web: 실제 Core 입력의 한국어 경험 정보창·모바일/데스크톱·저장 재접속·오류/overflow 검사. 화면 fixture와 실제 Core 실행을 구분.
- 병합 전 정확한 head의 필수 CI, 병합 후 Runtime Release/Pages/External Probe 및 실제 배포 source 확인.

현재 **M1-01~06 구현·검증·병합·배포 완료, M1-07 실제 신경망 추론 인수 미완**이다. 두 시드 1000일·native/WASM·출처/저장/반응형 근거와 실제 초기화 실패를 구분한다. 일반 지형의 고도에 의한 가림, 임의 음원 전파, 다른 주민의 내부 의도·보이지 않는 동물 소리는 구현했다고 주장하지 않는다.
