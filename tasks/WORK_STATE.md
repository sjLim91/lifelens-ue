## 3. New canonical time rule

Target observation speed:

- Pause — 0x.
- 1x — **8 real minutes = 1 LifeLens day**.
- 4x — 2 real minutes/day.
- 16x — 30 real seconds/day.
- 64x — 7.5 real seconds/day.
- History — adaptive long-run simulation, decoupled from render FPS.

The current runtime default before T1 is `0.6 real sec / simulation minute`, approximately 14m24s per simulation day.
T1 will replace this with the canonical 8m/day target (`0.333333... real sec / simulation minute`) and introduce safe variable speed controls.
