# COG-GOAL B3b — Core 개인 문맥으로 동적 목표 후보 생성

> 2026-10-12. 기준 계약: `docs/architecture/AUTONOMOUS_LIFE_AUTHORITY_BOUNDARIES_v1_2026-10-12.md`
>
> **상태: 결정론적·읽기 전용 로컬 목표 후보 생성기. 주민의 실제 Goal/Action/Simulation은 변경하지 않음.**

## 새로 구현한 것

`Source/LifeLensCore/include/lifelens/AutonomousGoalComposer.h`는 이미 Core가 만든 제한된 `CognitiveRequest`에서 실제 목표 후보(`AutonomousGoalCandidate`)를 계산한다. 이제 B3의 타입/검증 계약뿐 아니라, **개인별 문맥을 반영하는 실행 가능한 C++ 후보 생성 함수**가 존재한다.

1. 자신의 생리적 압력이 실제 문맥에 관찰될 때 Need 개선 목표 후보를 만든다. 이는 `UtilityAI` 실행 점수나 Needs 감소율을 변경하지 않는다.
2. 관계가 실제 인지 문맥에 들어와 있으면 관계적 목표 조건을 후보로 생성한다. 성격상 사회성·공감성 및 기존 신뢰도에 따라 **같은 환경이라도 주민별 후보 우선순위**가 달라진다.
3. 수원/음식/위생 등의 과거 경험은 `CognitiveMemoryEvidence.source`를 구분해 자신의 문제 중요도를 결정하는 **제한된 보조 근거**로 사용할 수 있다. 직접 목격은 소문보다 높은 증거 가중치를 받을 수 있지만, 둘 다 객관적 월드 진실 증명이 아니다.
4. 생존 목표 두 개 혹은 생존+관계 목표를 **새로운 AND 조건으로 조합**할 수 있다. 이는 정해진 문명 해금 과정이나 행동 스크립트와 무관하다.
5. 모든 후보는 기존 `validateAutonomousGoalCandidate`를 통과해야 하고 최대 6개까지만 반환한다. 안정적인 순서·동점·현재 시각/유효기간·임계값을 유지하며 전역/월드 난수에 접근하지 않는다.

## 구현 계약

- **생성 입력:** `const World&` (최종 검증용), Core에서 생성한 `const CognitiveRequest&`, 반환 개수 한도.
- **출력:** 0~6개의 typed 목표 후보. 후보에는 actor, minute, expiry, 1~6개 목표 상태 조건, 개인의 근거 참조, 0..1 priority가 포함된다.
- **서로 다른 주민:** 똑같은 Needs에서도 성격/관계/기억 출처 차이에 따라 다른 목적 후보가 우선할 수 있다.
- **Core 권위:** 후보 생성은 actor의 생존·실재 및 목표 target의 Core feasibility를 검증하기 위해 World를 전달받지만 **주민에게 World 진실을 지식으로 주입하지 않는다**. 사회 목표의 대상은 반드시 개인 request의 관계 목록에서 온다.
- **실패 처리:** ghost actor, 잘못된 분/trigger, 유한하지 않은 Needs, 실행 불능 target, 상한 초과 후보는 안전하게 건너뛰거나 빈 목록 반환.
- **성능:** 상한 8개 수준의 기존 CognitiveRequest 메모리/관계 맥락과 최대 6개 후보 조합. 매 프레임 모델 API 호출/Cloud 사용 없음.
- **저장·재생:** generator 결과를 권위 입력 이벤트로 저장하거나 과거 수락 결정을 재질의하지 않는다. 이 단계는 read-only이므로 SnapshotVersion=3 / BinaryFormat=8 불변.

## 근본 한계 (완료로 오해 금지)

- 이 알고리즘은 무료·결정론적인 **기초 생성기**다. 주민이 전혀 새로운 과학/기술/가설을 언어적으로 발명하는 범용 AI는 아니다.
- 현재 생성 목표 상태의 기본 변수 범위는 개인 Needs와 인지 문맥에 존재하는 관계 신뢰도이다. B3의 물질 재고 목표는 **개인 CognitiveRequest에 검증된 인벤토리 관찰치가 없어 자동 생성에서 제외**한다. 미관찰 월드 자원량을 추론한 척하지 않는다.
- 원자 행동 primitive와 계획 합성, 시도/성공/실패, 가설을 실제 실험으로 연결하는 실행기는 아직 없다. 따라서 이 PR은 실제 주민 행동 변화나 창발 문명 성과를 주장하지 않는다.
- 목표 우선순위를 기본 생존 Utility에 연결하지 않는다. 긴급한 Needs를 인지 보상·실패 기억 때문에 방치시키는 이전 회귀를 반복하지 않는다.
- 소문/잘못된 기억은 생각할 **이유**가 될 수 있지만, Core가 세계의 진실이나 실제 결과로 수락한다는 뜻은 아니다.
