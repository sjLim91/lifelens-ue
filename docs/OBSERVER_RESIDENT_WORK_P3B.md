# LifeLens P3-b — 실제 주민 작업·운반·손 소품 인과 정합

기준: main d6f4a3e3 (#1043 P3 시설 근접 관찰). 구현 범위: Web observer 전용.

## 이번 작업의 목적

Core가 보고한 주민의 작업·이동·물품 보유 사실과 화면에 등장하는 소품·손 동작을 연결한다.
인물·도구·자원을 가짜로 생성하지 않고 **Core-owned state가 확인된 경우만** 표현한다.

## 구체적 변경

1. **운반 중 표시 검증**: 이전에는 `Moving` 상태의 화물 표시가 인벤토리 소유량과 행동 종류만
   충족하면 Core 대상 시설/저장소가 실제로 존재하고 목표 좌표와 일치하는지 확인하지 않아도
   뜰 수 있었다. 이제 `ResidentProductionTargets.resolve()`를 통해 현재 Core
   시설·자원·저장소의 실제 ID, 물질·상태·목표 접근 좌표 일치 여부를 검사하여 운반 소품을
   표시한다. 정보가 누락되거나 불일치하면 소품을 숨긴다.
2. **실제 몸 위치와 손 행동 일치**: 기존 보간된 주민의 몸이 아직 목적지에 도착하지
   않았으면 손동작을 막고 실제 운반 화물만 표시하는 동작은 유지한다. 몸이 도착하고
   해당 대상과 실제로 상호작용할 수 있을 때에만 작업용 손 방향을 계산한다.
3. **채집·가공·보관 시선**: 기존에는 주민·주민 상호작용 중에만 시선을 맞췄다.
   이제 유효한 Core 작업 대상으로 검증되고 주민이 실제 접근 위치에 있는 동안
   기존 손이 향하는 **동일한 관측 대상**으로 시선도 유도한다. 이동 중·허위/원격
   목표·실체 없는 장소에 시선/손 동작을 생성하지 않는다.
4. **그림풍 손 소품 재질**: P1의 `?world-style=illustrated` 모드에서만
   이미 표시 중인 실존 물품/도구 메시의 면 음영을 통일한다. 재질만 변경하며
   화물의 형태·물질 종류·개수·모델 삼각형·소유권은 바꾸지 않는다.

## 기존 사실과 보호 범위

- 무장/장착 정보가 없는 물품은 임의 장비를 허리에 달지 않는다.
- 채집 도구는 기존 Core `artifactTool`·`contextActionToken`의 명시적 검증을 유지한다.
- 실제 재고가 소진되면 물품 표시도 사라진다.
- 주민 위치·이동 속도·작업 성공·제작 품질·소지 수량은 Web에서 결정하지 않는다.
- LifeLensCore / WASM ABI / 저장포맷 / 주민 AI / 시설 경제 / 핵심 자원 추적 변경 없음.
- 추가 GPU 컨텍스트·인스턴스 대량 생성·유료 런타임 없음.
- Android GPU 없는 Canvas 호환 경로는 그대로 유지한다.

## 회귀 인수

`web/tests/presentation/resident-work-p3b-checks.mjs`에서 직접
`ResidentProductionTargets` 및 실제 `ResidentInventoryProps`를 사용해
실존 대상, ID 불일치, 목표 좌표 불일치, 비가용 Core, 빈 인벤토리,
도착 전 보간·이동 중 소품 표시, 스타일 간 소품 정점 동일성 검증.

Web typecheck, 전체 회귀·빌드, PR Preflight 후 사전 승인된 `main` 병합,
GitHub Pages 및 외부 브라우저 WASM Core 기동 검증한다.

## 미완료 범위

이번 변경만으로 주민 손·손가락 관절의 물건 그립, 원물 메시의 접촉/채집·가공
애니메이션 전체의 사실적 완성도 또는 모바일 실기기 FPS를 입증할 수 없다.
다음 범위에서는 시각 QA 캡처와 실제 도구 파지, 시설 안팎으로 들어가는
물품의 순간 표현을 검증한다.
