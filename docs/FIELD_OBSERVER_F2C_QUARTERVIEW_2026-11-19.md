# LifeLens — F2-c 실제 쿼터뷰 2.5D 시각 개선

기준: 2026-11-19 `main@beee8e3f` (F2-b #1052).

## 사용자 관찰

기존 F2-b 모바일 화면은 이름과 달리 사실상 2D 정면/탑다운 이미지 배치였다.
`field-projection.ts`에서 화면 X는 Core X와 일치하고, Y만 .76으로 압축해
땅이 평면적으로 보였다. 토끼 크기도 주민에 근접했고, 관찰 날씨가 필드 렌더러로
넘어가지 않아 21시·비가 화면과 무관했다.

## 변경

1. **Grounded quarter-view projection**: 두 Core 수평축을 서로 반대 방향
   대각선으로 사영, 실제 관측 고도에 의해 발좌표/지면을 상승시킴. 역투영은
   같은 행렬을 정확히 되돌려 클릭/카메라 패닝/선택이 Core 위치를 유지한다.
2. **실제 고도 기반 음영**: 기존 17×17 Core elevation sampler를 유지하고,
   경사지의 지표 경계와 저비용 잔디 브러시로 2.5D 입체·지형감을 보강한다.
3. **시각 객체 비율**: Hare를 주민의 절반 미만으로 축소하고 Deer, 나무, 바위,
   꽃, 시설물의 상대 크기를 다시 조절한다. 개체 수, 자원, 시설 위치는 변하지 않는다.
4. **지면 접촉**: 오브젝트의 실제 투영 발좌표에 작은 그림자를 추가한다.
   전경 깊이 정렬 및 선택 주민 표시 최상위 보장 유지.
5. **Core 날씨/시간**: `WorldOverview.minute` 및
   `DynamicEnvironment`를 2.5D 렌더러에 전달한다. 실제 일조·시각에 따른
   야간 명암, 실제 강수 상황에서만 비·눈을 가볍게 표현한다. 날씨 자체는 생성하지 않는다.
6. **모바일 Chrome**: 필드 한정 상단 HUD와 하단 메뉴의 수직 면적을 줄인다.
   행동/선택 메뉴는 유지한다.

## 불변 계약

- Core C++/WASM, AI 판단/동선, 시설·자원·동물 생성, 영속화는 변경 없음
- 사용자 월드 시드·GUID·실제 투영 Core 좌표·선택/터치 역변환 유지
- 웹 캔버스만 사용; 신규 GPU/WebGL 컨텍스트 및 유료 외부 자산 없음
- 사진과 동일한 완성형 2.5D 게임 퀄리티를 달성했다고 주장하지 않는다.
  실기기 QA는 사용자의 요청대로 제외한다.
