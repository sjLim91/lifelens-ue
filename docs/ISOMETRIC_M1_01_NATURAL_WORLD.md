# LifeLens 2.5D — M1-01 자연환경 가독성 개선

기준: M0 main 37c1bc3b (#1046). Web Canvas 2.5D presentation 전용.

## 실제 문제

모바일 M0 관찰 화면에서 수계는 굵은 청록색 직선으로 표시되고,
높이 차이는 낮게 보여 지형이 평평했으며,
식생은 작은 삼각형이 반복돼 지형과 나무의 구별이 어려웠다.

## 구현

- **수계:** Core `hasDownstream=true`와 실제 관측된 인접 수계 청크가 함께
  존재할 때만 곡선 리본으로 연결한다. 관측 창 밖이나 한 칸을 넘는
  단절 구간은 가상 연결하지 않는다. 폭은 화면 LOD를 위해 상한이
  있는 *시각적 굵기*이고 실제 하천 물리 폭이나 가용 수량을 뜻하지 않는다.
  둑, 수면, 반사선을 분리한 저채도 색조를 사용한다.
- **고도:** 기존 Core의 17×17 상세 고도 샘플은 유지하고 화면 전용
  연직 스케일을 0.72 → 2.35 × 청크 스케일로 높였다. 실제
  지형 샘플에 따른 사면 채광 명암차를 키우고 한 패치마다 반복되던
  랜덤 체크무늬 명암을 줄였다. 화면 역투영도 같은 스케일을 사용한다.
- **식생:** Core `forestCoverage01`로만 숲 장식 개수를 결정한다.
  월드 시드·청크 좌표에서 결정적으로 변형한 둥근 활엽수 수관,
  침엽수와 줄기·지면 그림자를 표현한다. Boreal/Taiga 생태는
  침엽수 비중을 조절한다. 실제 독립 `ResourceNode`를 생성하거나
  변경하지 않는다.
- **암석:** `rockCoverage01`이 관측된 곳만 명암 면을 가진
  작은 암석 실루엣으로 묘사한다.

## 보호 조건

LifeLensCore/WASM/저장값/주민 AI/시간/지형 지오메트리 계약/물리 수계/재고/지식
변경 없음. 모바일에서 동일한 Canvas 2D 렌더러 사용, 새 WebGL 패스
없음. M0 주민·유효 시설 흔적·정착지 선택과 줌/패닝은 유지.

## 자동 검증

- 원본 Core가 지정한 인접 수계만 곡선으로 묘사하고, 미확인 경로,
  건조 목표, 비인접 목적지에는 선을 잇지 않는다.
- 화면 하천은 기존 광폭 밝은 직선 대신 폭 상한을 갖는 곡선.
- 숲은 실제 피복률·생태·시드에 결정적으로 종속되며 단순 삼각형만
  반복하지 않고 유효 수관을 표현한다.
- 사면 명암 및 고도 역투영 검증, 기존 M0 클릭/시야/바이너리
  저장과 Web 전체 회귀 검증 후 병합·배포.

## 미완료

이 단계는 M1-01의 자연환경 비주얼 개선이다.
정교한 저지대 물 범람·유속 연출, 완전한 물/바다 경계,
주민 8방향 sprite, 개별 나무와 실제 자원 소유 연계, 시설
컷어웨이/종류별 일러스트는 후속 M1/M2/M3 범위다.
실기기 장시간 FPS나 실제 미관 인수는 자동 테스트만으로 증명할 수 없다.
