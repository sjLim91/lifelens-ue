# Core 지구 시나리오 연결의 영속 저장 — 2026-10-19

#799 돌봄 수정 위에 쌓은 독립 저장/관측 변경이다. 기존 단일 기원·
절차적 지형·지리 자료/미터 스케일 출처 계약을 바꾸지 않는다.

실제 공백: newEarthGame의 지리 연결이 WebClientBridge 객체에만 남아
새 브리지/재접속으로 Core 저장을 복원하면 사라졌다. 같은 seed의 일반
저장을 복원할 때는 반대로 예전 브리지 지리 연결이 남을 수 있었다.

구현: World가 명시적 EarthScenarioState를 소유하고, Core 바이너리
코덱이 선택적 버전 확장을 기록한다. 일반/기존 월드에는 확장을 쓰지
않으므로 기존 바이트 계약을 유지한다. 시드/생성 버전·좌표·양의
유한 스케일·자료 출처를 검증한 뒤에만 복원을 커밋한다. 저장된 Core
연결에서 브리지 관측 카탈로그를 재구축하고 일반 저장은 이전 연결을 지운다.

Web은 snapshotPersistence의 Core boolean 계약을 읽으며 지형이 실제
지구 자료로 조건화되었다고 바꾸지 않는다. 무료 오프라인 저장 경로를
사용하고 별도 브라우저 시뮬레이션 저장 형식을 도입하지 않는다.

회귀: 새 브리지 복원, 지리/태양 관측 연속성, 같은 seed의 일반 저장으로
전환, 손상 입력의 원자 거부, 시드/좌표/스케일/자료 토큰 거부, 구버전
일반 저장과 지구 저장의 byte-stable 재인코딩을 검사한다.
