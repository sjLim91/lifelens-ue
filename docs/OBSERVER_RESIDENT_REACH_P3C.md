# LifeLens P3-c — 주민 채집 손·시선의 실제 도달 범위

기준: main 916bcb9 (#1044, P3-b). Web observer 순수 표현 개선.

## 발견

현재 주민 상호작용 장면에서 채집의 Core 자원 노드 중심이 작업자 위치(접근 셀)보다
멀면, 기존 손 2-bone IK가 `residentHeight * .65` 범위 바깥의 목표를 거부하여
손 동작이 거의 나타나지 않을 수 있다. Core는 자원 접근 셀과 실물 자원 노드
중심이 서로 다를 수 있도록 허용한다. 이는 시뮬레이션 결함이 아니라 시각
동작의 표현 문제다.

## P3-c 변경

- 유효한 `ResidentProductionTargets` 및 `Interacting` 검증은 P3-b 그대로 유지.
- 실제 주민의 현재 `rightArm` 어깨 세계 좌표에서 채집 대상 방향을 구하고,
  `height * .58`를 넘지 않는 **팔 제스처 목표**만 기존 2-bone IK에 전달.
- 눈/머리는 별도 복사해 둔 **실제 Core 자원 중심**을 바라보며, 가까운 접근 셀의
  가상 손 목표를 자원 위치로 착각하지 않도록 한다.
- 실제 자원에 손이 닿았거나 수량이 증가/감소했다고 주장하지 않으며
  임의의 재료 이동·채집·인벤토리 변화는 만들지 않는다.
- 시설/저장소 원래 손 목표는 변경하지 않는다. 어깨 뼈가 없거나 지형/검증이
  불가능한 경우 제스처를 새로 생성하지 않는다.
- 새 모델·텍스처·개별 메시·AI 판단·저장 타입·Core ABI 변경 없음.

## 자동 검증

- 유효한 목표는 정확히 어깨로부터 58% 신장 이내,
  목표로 향하는 방향은 유지, 원본 Core 노드 위치 불변.
- 가까운 대상은 원래 좌표 그대로, NaN/Inf/무효 신장은 비표시.
- 실제 ResidentWorldLayer와 검증된 채집 노드/접근 셀을 이용한
  통합 테스트: Core 물체 방향으로 시선 유지, 손은 한정된 범위,
  주민 위치·이동 데이터 변경 없음.
- PR Typecheck, Web 전체 회귀, 프로덕션 빌드, Preflight,
  병합 후 Pages 및 외부 Core 브라우저 부팅 검사.

## 검증하지 않은 것

실제 영상 기반 손가락 파지, 재료 소진 프레임과 애니메이션의 정확한 동기화,
실기기 발열/성능, 완전 AAA 수준 근접 그래픽은 이번 소규모 변경의 범위 밖.
