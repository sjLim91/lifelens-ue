# LifeLens P3 — 주민 관찰 근접 시설 정합성

상태: 실제 Web presentation 구현 및 검증 대상
기준: main ec110e4a (#1042, P2)

## 문제와 범위

LifeLens는 자동 생성 RPG가 아니라 Core의 실제 주민·시설·자원 인과를 관찰하는 시뮬레이션이다.
P3에서는 가까운 거리에서 관찰하는 시설의 위치와 내부 표시를 정합화한다.
**기존 AI·행동·건설·경제·자원·저장·Core를 변경하지 않는다.**

### 이번 변경

1. **시설 상세 고도 정합**: 기존 FacilityLayer 캐시는 주변 청크의 대표 `elevation01`만 추적했다.
   동일한 청크 평균 고도여도 실제 17×17 상세 고도 격자가 변하면, 시설의 배치 높이가
   낡은 상태로 남을 수 있었다. 이제 각 실제 시설 위치에 대한 Core 상세 고도 샘플 값을
   배치 시그니처에 포함하며, 해당 지점만 샘플링한다.
   다른 청크의 조명/자원 변화로 불필요한 시설 메시를 재생성하지 않는다.
2. **실제 저장시설 내부 관찰**: `WorldScene.setSelectedHumanTrace`와 시설을 연동한다.
   실존하는 운영 중 저장시설이 Core 시설 상세의 `linkedStorage`를 가지고 있을 때만
   선택 시 기존 지붕/상부 패널을 감춘다. 선택 해제 시 원상복구한다.
   기존 `Store`/`Retrieve` 중 주민 실제 동작에 의한 컷어웨이는 보존하며
   두 조건을 OR로 결합한다. 빈·미연결·건설 중 시설에 가짜 물품을 만들어 보여주지 않는다.
   실제 건물 메시를 재구성하지 않고 기존 패널 가시성만 변경한다.
3. **그림풍 근접 시설 재질**: P1의 `?world-style=illustrated`에서만 기존 재질의
   목재·석재·토양·짚·침구 색채와 면 음영을 다듬는다.
   시설 종류, 개수, 위치, 손상, 저장 물품, 자원, 날씨 관련 셰이더 및 경로는 유지한다.

### 회귀 검증

- 실제 `FacilityLayer`와 `WorldScene`을 이용한 테스트.
- 같은 평균 고도 `elevation01`에서 상세 `elevationSamples`만 변할 때 시설 높이 갱신.
- 선택한 운영 중 실존 `linkedStorage`의 상부만 감추고 선택 해제 시 원복.
- 실제 보관·인출 중 작업 가림 처리 유지.
- 연결 없는 시설이나 관계없는 선택으로 임의의 저장시설 내부를 표시하지 않음.
- 기존 그림풍 스타일은 선택적이며 기본 3D 모드의 색상과 오브젝트 수 불변.
- Web typecheck, 전체 회귀 테스트, 프로덕션 빌드, Preflight, Pages 배포 및 외부 Core 부팅 검증.

## 남은 후속 개발

본 PR은 고품질 캐릭터 모델·모션·자원 원물 모델의 전체 교체가 아니며,
'주민 근접 3D가 참조 게임 품질에 도달'한 것으로 주장하지 않는다.
확장 P3-b에서는 장면별 시각 QA에 근거해 실제 주민 작업 손·자원 채집 소품·시설
상호작용 간의 충돌 및 가림을 별도 개선한다.
모바일 장시간 FPS/메모리 개선도 별도의 실측 대상이다.
