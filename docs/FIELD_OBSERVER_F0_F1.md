# LifeLens 현장형 2.5D 전환 — F0 + F1 첫 작동 수직 슬라이스

기준: `main` 6d324ece (#1048). **Web 표시 계층만 변경**한다.

## 기존 방식과의 차이

지금까지의 `?view=2.5d`는 Core 좌표를 45° 다이아몬드 지도에
단색 타일·원/삼각형 마커로 옮긴 지역 지도였다.
사용자가 제시한 레퍼런스는 지도가 아니라 **높은 위치에서 가까이
보는 탑다운형 2.5D 현장 게임 화면**이다. 기존 지도에 하천 선과
나무 원을 계속 추가해서는 목표에 접근할 수 없다.

## F0

- 현장 독립 렌더러 `field-observer-renderer.ts` + 투영
  `field-projection.ts` 추가.
- 현장은 정면 X축, 압축된 화면 Y축, Core 높이에 따른 수직 보정.
  기존 45° 아이소메트릭 다이아몬드 경로는 지도용으로 유지한다.
- `?view=2.5d`와 `?view=field` = **현장 관찰**,
  `?view=region` = 기존 2.5D 지역 지도,
  `?view=3d` = 기존 3D QA 경로,
  `?view=legacy` = Canvas 비상 경로.
- 상단 버튼은 현장/지역 지도 간 전환을 제공한다.
  현재 기본값의 자동 승격과 3D 코드 삭제는 F4/F5 인수를 통과한 뒤 수행한다.
- PC/모바일 드래그, 줌, 터치 선택, 실제 Core 고도 역투영,
  ResidentContinuity, WorldSession 정보 읽기·선택 동기화 유지.
- 새 Field Sprite는 Canvas 2D에서만 그린다. WebGL 컨텍스트 추가 없음.
- 3D/현장 실패 시 WASM Core를 중단하지 않고 기존 Canvas 경로로 복구한다.

## F1 시각 자산

자체 제작 **13개의 원본 투명 SVG 스프라이트**:
- 수종(침엽수 두 종류, 활엽수), 덤불, 꽃
- 큰 암반/절벽, 작은 암석
- 남녀 주민 임시 2.5D 초상/몸통
- 실제 관측된 사슴, 토끼
- 시설 작업장/거처, 실제 화덕

`field-asset-atlas.ts`가 브라우저별 SVG Image 인스턴스를 단 한 번씩
캐시한다. 이미지 갱신이 완료되면 화면을 다시 그리며 개체마다 이미지를
생성하거나, 외부 CDN, 유료 이미지 서비스, GPU 셰이더를 요구하지 않는다.
GitHub Pages 상대 경로 `./field/name.svg` 사용.

## 진실값 계약과 배치

- WorldSession `TerrainWindow` 17×17 고도 격자에 따라 바닥,
  지표 색, 높이, 실제 수계만 그린다.
- 나무/덤불/꽃/암반 등의 장식 밀도와 분포는 **Core의
  `forestCoverage01`, `shrubCoverage01`, `grassCoverage01`,
  `rockCoverage01`, `biome`, worldSeed**로 계산한다.
  이들은 단일 채집 자원 노드나 벌목 대상이라고 속이지 않는다.
- `visibleHumanTraces()` 검증을 통과한 **실존 시설 흔적**만
  건물/화덕 그림을 표시한다. 정착지는 `active` 실존 ID만.
- 주민 위치는 ResidentContinuity의 현재 Core 관측 지점,
  동물은 실제 Core `wildlife.animals` 개체만 보여준다.
  현재 원본 에셋이 있는 Deer/Hare만 그리며 다른 종을 잘못된
  동물로 바꿔 표시하지 않는다. F2 전체 동물 종 이전 대상.
- 큰 암반/수목/동물/주민/시설은 같은 화면 Y 깊이 순서로 정렬한다.
  단, 월드 시뮬레이션 이동/소지품/행동 결과에 영향을 주지 않는다.
- 클릭/선택 링과 실제 주민의 이름은 원본 DTO에서만 읽는다.

## 완료했다고 주장하지 않는 범위

- F1의 **레퍼런스와 같은 AAA급 손그림 에셋 완성도**는
  자동 테스트나 단순 파일 생성으로 증명되지 않는다. 실제 화면
  시각 QA 및 모바일 장시간 프레임 성능을 별도로 확인해야 한다.
- F2 개체별 외모·8방향 애니메이션·모든 종 동물,
  F3 시설별 정확한 외형/내부 컷어웨이/재고 소품,
  F4 모바일 상세 UX 및 성능, F5 기본 뷰 승격 및 3D 정리는 미완료.
- 새 그림은 **게임 현장 그래픽으로 넘어가는 첫 작동 가능 수직 슬라이스**다.
  예전 지도형/도형형 화면을 곧바로 완성품으로 보고하지 않는다.
