# 돌봄 기회의 실행 가능 후보를 먼저 검증 — 2026-10-19

기준 main: ad7062c065fa9915eb02c7e0cb286c47b34e3952 (#798).

실제 재현: 일상 발달 욕구가 높은 아동의 배고픔 0.70, 실제 음식이 있는
부모, 정규 30분 돌봄 창에서 chooseParentingAction이 교육 후보를 선택할 수
있었다. 호출자가 교육 시간을 검사해 그 후보를 버리면서 가능한 Feed까지
고려하지 않았다. 이는 새로운 육아 규칙이 아니라 기존 시간 제한을 후보
최대화 이후에 적용한 순서 오류다.

수정: 일상 발달 행동(Play/Educate/Discipline)과 진정 행동(Hold/Comfort)의
현재 창 허용 여부를 후보 선택에 전달한다. 후보를 먼저 걸러낸 뒤 기존
효용식 그대로 최대화한다. 직접 API 호출은 기본값으로 이전 행동을 유지한다.
물자, 부모/공동체 자격, 실제 이동, 생존 선점, 점수 상수는 변경하지 않는다.

회귀: 모델 입력 없이 실제 부모·아동·음식을 구성하고 정규 창에서 Feed
토큰이 발행되는지 검사한다. 실제 재고 1개 소비·배고픔 감소·중복 ACK 거부,
바이너리 저장/복원 동일 결과를 검사한다. 외부 물리 실행 여부는 클라이언트
어댑터 선택이므로 복원한 테스트 클라이언트가 명시적으로 다시 설정한다.

이 변경만으로 #653의 위생시설 왕복 중 모든 중단/인계 시나리오나 장기 건강
인과 과제를 종료하지 않는다. 후속 결과는 정확한 HEAD Actions로 기록한다.
