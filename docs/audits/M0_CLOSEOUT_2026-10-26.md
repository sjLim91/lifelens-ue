1000일 체크포인트에서 생성 후 **365일 이상 지난 기록**은 시드 4242001에서 **33,976/57,312건(약 59.3%)**, 874213954에서 **10,636/15,450건(약 68.8%)**이었다. 장기 보존된 과거 기억이 높은 전체 규모에 기여하지만, 이것만으로 누수라고 판정하지 않는다. 오래된 기억의 계층화·회상 품질·삭제 정책 변경은 별도 M1/M11 계약이 필요하다.

**분석 경계:** 메모리 텍스트 바이트와 전체 스냅샷 바이트는 같은 값이 아니다. 기억의 높은 증가율 자체는 확정적인 메모리 누수 증거가 아니다. 직접 목격 출처라는 꼬리표만으로 실제 Core 행동 성공이 입증되지는 않는다.

## M0-03 14개 의도별 주민/실행 증거

실제 결과 원본: [100/365/1000일 × 두 시드 Core 비교](https://github.com/sjLim91/lifelens-ue/actions/runs/40284406855). 이 실행의 **6개 native job은 모두 성공**했고 주민 ID별·의도별 선택/수락/거절 합계 및 Core 교육/교역/돌봄 종료결과 3종을 직접 대조해 정합성을 확인했다. 기존 종료 보고서 단계는 Python 모듈 호출 오류 때문에 실패했으며 #970의 새 head에서 수정되어 재검증이 필요하다.

| 시드 | 1000일 인지 제안 제출·수락 | 실제 교육 성공 | 실제 교육 실패 | 교역 Core 완료 | 양육 Core 완료 |
|---|---:|---:|---:|---:|---:|
| 4242001 | 80,151 / 80,151 | 0 | 20 | 0 | 0 |
| 874213954 | 89,143 / 89,143 | 1 | 78 | 0 | 0 |

시드 874213954의 1000일 실행에서 `CareForDependent`는 대상이 없다는 이유로 **6,857회** 제출하지 않았다. 주민별/카탈로그별 이 수치를 대조했다. 14종 목록이 등장한 사실과 14종이 Core에서 모두 실행됐다는 주장은 별개다.

**명시적인 미입증 사항:** 실제 물리 완료를 뜻하는 Core context 이벤트가 측정된 것은 교육·교역·돌봄 3종뿐이다. 이들조차 "개별 인지 의도가 결과를 직접 유발했다"는 인과 연결 증거는 아니다. 나머지 11종은 이 감사에서 **의도별 Core 종료 영수증 미계측/인과 미검증**으로 보고한다. 코드가 지원하지 않는다는 단정도, 실행 완료라는 허위 주장도 하지 않는다. 이 연결을 실제로 완성하는 작업은 M2/M3의 자율 Core 실행·실험 검증 대상이다.

## 장기 이슈와 M0 감사 사이의 경계

- [#790](https://github.com/sjLim91/lifelens-ue/issues/790) 14개 전략 의도 중 아직 실제 Core 행위·terminal 영수증이 완결되지 않은 종단 실행 경로: 감사 결과와 실제 부족한 행동 연결을 기록했지만 **실제 에이전트 구현 과제가 남아 OPEN 유지**. M2/M3에 연결된다.
- [#669](https://github.com/sjLim91/lifelens-ue/issues/669) 자율학습에 따른 Memory/Snapshot 증식과 성능/보존 정책: 시드·시간·태그/출처별 분해 원본 데이터를 기록했지만, **기억 보존 정책·성능 문제 해결까지 입증하지 않아 OPEN 유지**. M1/M11과 연결된다.
- M0의 감사 계약 완료는 14개 주민 전략을 모두 *실행*한다거나 기억 증가의 완전한 물리적 *원인*을 제거했다는 뜻이 아니다.
