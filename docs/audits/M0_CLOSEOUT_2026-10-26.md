## M0-03 14개 의도별 주민/실행 증거

실제 결과 원본: [100/365/1000일 × 두 시드 Core 비교](https://github.com/sjLim91/lifelens-ue/actions/runs/40284406855). 이 실행의 **6개 native job은 모두 성공**했고 주민 ID별·의도별 선택/수락/거절 합계 및 Core 교육/교역/돌봄 종료결과 3종을 직접 대조해 정합성을 확인했다. **초기** 종료 보고서는 Python 모듈 경로 문제로 실패했지만, 수정된 #970 head `ac9c3634`에서 [6개 시뮬레이션+후처리 closeout 전부 PASS](https://github.com/sjLim91/lifelens-ue/actions/runs/40287506442)했다. 보고서 미기록을 성공으로 보간하지 않는다.

| 시드 | 1000일 인지 제안 제출·수락 | 실제 교육 성공 | 실제 교육 실패 | 교역 Core 완료 | 양육 Core 완료 |
|---|---:|---:|---:|---:|---:|
| 4242001 | 80,151 / 80,151 | 0 | 20 | 0 | 0 |
| 874213954 | 89,143 / 89,143 | 1 | 78 | 0 | 0 |

시드 874213954의 1000일 실행에서 `CareForDependent`는 대상이 없다는 이유로 **6,857회** 제출하지 않았다. 주민별/카탈로그별 이 수치를 대조했다. 14종 목록이 등장한 사실과 14종이 Core에서 모두 실행됐다는 주장은 별개다.

**명시적인 미입증 사항:** 실제 물리 완료를 뜻하는 Core context 이벤트가 측정된 것은 교육·교역·돌봄 3종뿐이다. 이들조차 "개별 인지 의도가 결과를 직접 유발했다"는 인과 연결 증거는 아니다. 나머지 11종은 이 감사에서 **의도별 Core 종료 영수증 미계측/인과 미검증**으로 보고한다. 코드가 지원하지 않는다는 단정도, 실행 완료라는 허위 주장도 하지 않는다. 이 연결을 실제로 완성하는 작업은 M2/M3의 자율 Core 실행·실험 검증 대상이다.
