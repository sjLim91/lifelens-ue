# LifeLens 2.5D 현장 화면 — F1-b 시인성·시설 정합성 작업

기준: main f2074ad8 (#1049) F0/F1 오리지널 SVG 첫 화면.
참고: 사용자가 제공한 모바일 현장뷰 스크린샷은 같은 모양 집 밀집,
주민 가림, 반복된 둥근 나무, 커다란 사건 패널을 보여준다.

## 우선순위 재정렬

1. **기본 시뮬레이션 사실 표시**: 실제 Core 시설 종류가 다른데 같은
   집으로 보이는 문제부터 수정한다. 종류가 다른 시설의 화면 묘사를
   통일할 수 없으며 건설 중을 완성된 시설처럼 표시하지 않는다.
2. **주민 관찰성**: 식생은 설명용 배경이고 주민이 관찰 주인공이다.
   실제 주민·작업장 좌표 근처의 시각적 장식 배치를 제어하고,
   주민 위를 덮는 전경은 반투명하게 만든다. 선택 표시/이름은
   모든 전경 뒤에 마지막으로 올린다.
3. **반복/혼잡**: F1의 동일한 숲 스프라이트가 고밀도로 반복되던
   화면용 배치 수를 제한한다. 실제 Core 산림 피복률, 자원이나
   동식물 개체 수를 줄이지 않는다.
4. **모바일 UI**: 최근 관찰은 기본 한 줄 상태로 시작하고
   터치로 펼쳐 원래 사건을 열 수 있다. 알림 기록 자체는 감추거나
   버리지 않는다.

## 구현 파일

- `web/src/render/field-scene-clarity.ts`
  - 기존 Facility의 **정확한 종류 문자열**에 따라 Shelter/hut,
    PrimitiveStorage/store, WorkSurface/workbench,
    SleepingPlace/sleeping, FirePit/fire, Furnace/furnace,
    CultivatedPlot/farm 사용.
  - Planned/ruined/unknown 종류는 완성된 주택을 그리지 않고
    중립적인 site 마커로 표시.
  - 실제 Core 주민·시설·정착지·동물 위치를 보존하는
    시각적 sightline clearance 계산. Core 건설/물리 공간 변경 없음.
  - 화면 깊이를 고려한 전경 일러스트 알파 처리.
- `web/public/field/` 아래 원본 SVG 7종:
  `workbench, store, sleeping, furnace, farm, site, flag`.
  기존 13종과 합쳐 20종. 외부 이미지 서비스/유료 API 없음.
- `web/src/render/field-observer-renderer.ts`
  - 실존 시설 유형에 맞는 크기로 렌더링.
  - 정착지는 **행정상 관측 지점**이므로 추가 허위 주택이
    아니라 작은 기(flag)로 표시. 해당 선택 ID는 유지.
  - 시각적 숲 스프라이트 상한을 청크당 11 → 6으로 축소.
    숲 피복률·자원·주민 AI·동물 개체 수 변경 없음.
  - 주민 시각 크기를 확대하고, 선택한 대상의 링/이름을
    전경 위에 마지막에 렌더링.
- `web/src/ui/observation-feed.tsx`, `App.tsx`,
  `web/src/ui/observer-shell.css`: 모바일 현장뷰에서만
  사건 패널을 접힌 한 줄로 시작. 보기/접기 버튼
  aria-expanded 및 이벤트 선택 보존. 다른 렌더 모드는 영향 없음.

## 인수

- 모든 운영 시설 타입의 스프라이트 종류가 다름을 검증.
- 계획/폐허/알 수 없는 종류는 완공 집 이미지 사용 금지.
- 실존 정착지가 가짜 주택을 추가하지 않음을 검증.
- 실제 주민 및 시설 주변 시각적 장식은 가시성 여백 유지.
- 가림 시 알파 적용·선택 표시 우선순위 확인.
- 모바일 관찰 패널의 펼침·접기 요소 연결 검증.
- F0/F1과 M0/M1 전 단계 전체 회귀, TypeScript,
  프로덕션 빌드 및 Pages + 외부 WASM Core 기동 검사.

## 인정하지 않는 완성 범위

기존 참조 게임의 작화 밀도·애니메이션·절벽 규모를
완전히 재현했다고 주장하지 않는다. 실제 모바일 스크린샷
품질은 배포 후 비교해야 한다.
F2 주민 방향·행동·개인별 외모/모든 동물,
F3 시설 건설 단계 애니메이션·작업 소품,
F4 다중 리소스 인스턴싱 및 모바일 성능/UX를 별도 추진한다.
