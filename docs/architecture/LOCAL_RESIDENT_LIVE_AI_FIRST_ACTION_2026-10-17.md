# LifeLens 주민별 무료 로컬 AI — 실행형 최초 연결 (2026-10-17)

## 실제 변경
기존 read-only Cognitive Shadow를 제거하지 않고, 명시적 켜기로 작동하는 실행형 주민 AI를 추가한다.
한 개의 무료 로컬 OpenAI 호환 언어 모델이 모든 주민에게 공유되지만, Core가 보낸 주민별 Needs/성격/감정/기억 출처/믿음/관계는 각 추론마다 분리된다.
정해진 외부 유료 API는 사용하지 않고 loopback(127.0.0.1 / localhost) 모델 서비스만 허용한다.

1. Web Observer 500ms 관찰 갱신에 붙은 ResidentAIController는 생존 주민 32명까지 순환한다. 최소 5초 간격, 동시 1명, 대기열 0명, 모델 시간 제한 6초.
2. 인지 스케줄러가 주민 개인의 Core CognitiveRequest를 모델에 전달하고 엄격히 스키마를 검증한다.
3. 새로운 submitLocalCognitiveProposal WASM 경계는 월드 시드, 96분 수락 기한, 현재 주민과 대상의 생존, 허용 전략 Intent, priority, 짧은 근거의 digest를 다시 검증한다.
4. 승인된 CooperateWithResident / ResolveConflict는 Core가 일반 문명작업을 고르는 15분 주기에서 비긴급 상태, 실제 사회 점수 0.18 이상, 현존 대상, 일정 거리 이내 조건을 모두 통과할 때 사회 행동 기회를 얻는다. 실행은 기존 공간 경로/PendingContextAction이며 AI는 물리상태를 바꾸지 못한다.
5. 생존·제작·자원·교역·양육·이주 등의 다른 전략 판단은 아직 수락 기록에만 남으며 강제 실행하지 않는다.
6. AI 비활성/모델 미설치/응답 실패이면 기존 Core 단독 시뮬레이션이 그대로 작동한다.

## 사용법
- 무료 로컬 모델 서버에서 OpenAI 호환 /v1/chat/completions 를 제공하도록 실행한다 (기본 입력 http://127.0.0.1:8080). 모델 실행 자체는 LifeLens에 포함되어 있지 않다.
- LifeLens 주민 상세 메뉴의 주민 AI · 사고와 실제 행동 패널에서 URL과 모델명을 입력하고 주민 AI 시작을 선택한다.
- 이 연결은 반드시 사용자가 설정한 로컬 서버를 필요로 한다. 모바일의 localhost는 PC가 아닌 휴대전화를 가리키므로 PC 모델이 자동 연결되지는 않는다.
- 승인 수치는 Core 저널에 제안이 기록된 수치이며 실제 행동 완료 수치와 다르다.

## 검증 및 남은 작업
- Core CTest test_live_resident_ai 는 유효/무효 입력 차단, 실제 대화 대상 선택 변화, 저장·복원 재현성까지 검증한다.
- Web 인지 회귀 live.mjs 는 주민별 기억 격리, 라운드로빈, 늦은 응답/세계 교체 차단, 일수 건너뛰기 중 AI 정지를 검증한다.
- 다음 단계는 전체 Intent를 실제 Core 행동 affordance에 연결하고, 개인 목표 달성/실패 기록 및 로컬 추론 성능/장기 결정론을 검증하는 것이다.
- 이 첫 연결을 GPT급 자율 지능 완성이나 창발적 문명 구현 완료로 표현하지 않는다.
