# LifeLens Web 2.5D — M1-02 해안·호수·지면 입체감

기준: main 0fd35d8d (#1047 M1-01). 범위: 오직 Web Canvas 2.5D presentation.

## 개선 동기

M1-01은 하천·식생의 도형감을 개선했지만,
해안('Coast') 청크 전체가 파란색으로 칠해져 육지·바다의 관계가 흐릿했고,
호수 경계는 육지와 같은 사각형 청크 경계에 머물렀다.
평지 지면은 17×17 조각의 미세 색상 잡음으로 격자처럼 보였다.

## 실제 구현

1. **관측 기반 경계**: `observedShoreEdges()`는 Core가 동시에 관측한
   동서남북 인접 청크의 서로 다른 물 유형만 비교한다.
   `Ocean` ↔ `Coast/land` 또는 `Lake` ↔ `non-Lake`의 실제 공유
   경계만 보여준다. **관측되지 않은 인접 청크 밖에 해변/호수를 이어붙이지 않는다.**
   같은 Ocean/Lake끼리는 가짜 모래 경계를 만들지 않는다.
2. **해안 표현**: `Coast`는 육지 성격을 가진 모래톤으로 표시한다.
   바다 청크의 실제 경계에서만 명암을 가진 수변 띠·얕은 물색·밝은 거품선을
   겹친다. 호수도 진짜 관측된 육지 경계에만 수변선을 그린다.
   `shoreStrokeWidths()`는 모바일 화면에서 과도한 굵기가 되지 않도록
   상한을 적용한다. 흔들림은 월드시드 기반 선 굽힘일 뿐, Core 물의
   크기·높이·유속을 새로 계산하지 않는다.
3. **물 표면**: 오직 실제 `Lake/Ocean` 청크에만 소량의 수면 반사 무늬를 표시한다.
4. **격자 무늬 축소**: 지형 패치별 랜덤 명암을 청크별 미세한 통일 색조로
   변경한다. 지형 기울기 명암은 여전히 실제 17×17 Core 고도 샘플을 따른다.
5. **고저차 표현**: 하나의 청크 안에서도 실제 측정 높이 차이가
   충분히 큰 경우에 한해 저대비 토양/암반 능선선을 덧그린다.
   이것은 시각적 채광 요소이지 Core의 새 절벽·이동 장애물이 아니다.
6. **지면 질감**: `grassCoverage01`, `wetlandCoverage01`,
   `rockCoverage01`에만 종속되는 시드 기반 풀·습지·잔돌 질감을
   묘사한다. 개별 물품/자원 개체로 등록하지 않는다.

## 안정성 및 자동 검증

- `isometric-m1-02-checks.mjs`에서 실제 인접 바다/호수만 경계로 그림,
  미확인·동종 물 경계 금지, 해안 모래 색상, 좁은 물가 폭, 결정적 숲/초지
  피복, 실제 Core 고저차만의 시각적 경사 표현을 검증한다.
- 기존 M0/M1-01의 주민·시설 선택, Core 물 흐름, UI, 카메라,
  환경·물류·AI 회귀 테스트를 그대로 수행한다.
- LifeLensCore / WASM ABI / 주민 AI / Core 자원·지형·물리 상태 /
  저장 스키마 / 세계 시간 / 운영 비용 변경 없음.
- 새 GPU 컨텍스트, 텍스처 다운로드, 유료 런타임 없음.

## 후속 범위

호수/해안의 타일 스케일 이상의 세밀한 범람 영역·실제 프랙털 경계는
현재 Core의 수계 격자 해상도보다 높은 사실을 요구하므로 M1-03 또는
Core의 명시적 세부 관측 계약 확장 전에는 사실처럼 표현하지 않는다.
M2는 주민·동물 8방향 Sprite, M3은 실제 시설별 일러스트/건설 컷어웨이.

브라우저 Core 부팅과 자동 검사 성공은 실기기 비주얼·FPS 인수와 별개다.
