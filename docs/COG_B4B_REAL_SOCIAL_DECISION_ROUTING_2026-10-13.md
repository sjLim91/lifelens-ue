# LifeLens COG-B4b — 개인 목표에 따른 실제 사회적 상대 선택 (최초 Core 실행 영향)

> 2026-10-13 / 선행 B4a: `feat/cog-b4a-existing-affordance-plan-validation-20261013`, #704.

## 무엇이 달라졌는가

B3~B4a의 기존 변경은 모두 자율 목표 **후보/감사/계획 후보**였다. 이번 B4b는 실제 `Simulation::trySocialDecision`에서 이미 승인된 **기존 사회행동의 대상 선택**에 개인의 목표 후보를 반영한다.

- Core는 기존 `chooseUnifiedUtilityDecisionAtPosition` / `choosePhysicalSocialUtilityDecision`로 생존·문명·사회 중 어디에 시간을 쓸지 먼저 결정한다. **Cognition은 새로운 사회행동 시간을 만들지 않는다.**
- 결정 결과가 Social이면서 유효한 기존 대상이 있을 경우에만, 현재 주민의 8건 한도 개인 `CognitiveRequest`를 이용해 목표 후보를 조합한다.
- 관계 신뢰 개선이라는 실제로 표현 가능한 목표만, B4a의 같은 분/같은 주민/같은 기억 출처 `cognitiveRequestFingerprint`와 실제 Core 사회 점수로 재검증한다.
- 목표 후보가 다른 실재 주민을 지목하고, 기존 `SocialIntent::Approach/Repair`가 최소 사회행동 점수 0.18 이상이며 **기존 선택과 0.12 이내**인 가까운 대안인 경우에만 개인의 목표 선호로 순위를 변경할 수 있다.
- 강한 기존 사회 선택은 유지한다. 사회 여부를 새로 결정하거나, 나쁜 경험·소문을 객관적 월드 진실로 승격하거나, 관계 수치를 미리 증가시키지 않는다.
- 이후 실제 이동/도착/진행/실패/관계 변화와 로그는 **변경 전과 동일한 Core `PendingContextAction` 실행 경로**가 처리한다.

## 승인 게이트

1. Core가 사회활동을 선택하지 않았으면 변경 없음.
2. 기존 사회행동 쿨다운/주민 자율성/현재 Pending/긴급 생존 우선 검사 통과 필수.
3. 통상 15분 계획 경계에서만 개인 목표를 이용한 상대 재선택을 검토한다.
4. 허기·갈증·수면·배뇨·위생 중 하나라도 긴급 임계면 변경하지 않는다.
5. 개인의 현재 Core 기억·전언·관계 문맥 및 B4a 목표 타당성을 다시 확인한다.
6. 상대는 실제 `Character`로 존재하고 생존 중이어야 하며, 일상 사회 점수가 유의해야 한다.
7. 기존 사회 점수를 파괴하거나 추가 사회 활동 기회를 만들지 않는다.

## 변경하지 않는 것

- 실재 World 자원, 생물, 건축·기술·문명 발전 강제, 시설 이동 규칙, 긴급 Needs Utility, 사회 결과 공식·시간 진행·건강.
- 사회행동 타깃이 다르기 때문에 **시뮬레이션의 후속 관계 역사·인과 결과는 정상적으로 달라질 수 있다**. 이 동작 변화는 실제 기능이므로 B4a와 구별한다.
- 새 Snapshot 필드, enum ordinal, RNG 사용, COG-3 accepted event 위조, Web/WASM API, 외부 서비스/유료 모델 추가 없음.
