# LifeLens — 자율 사고·경험 학습·창발 문명 구현 로드맵 (2026-10-13)

## 제품 목적과 엄격한 경계

LifeLens의 목표는 주민이 그럴듯한 GPT 대사를 출력하는 것이 아니라, **같은 세계의 제한된 감각·개인 기억·가설·행동·결과·사회적 학습**을 사용하여 자기 삶과 사회를 변화시키는 것을 관찰하는 것이다.

- Core C++ 단일 물리/사회/자원/관계/기후 실행 권한. AI 제안, 기억과 믿음은 월드의 객관적 진실이 아니다.
- 기본 실행은 무료·오프라인·시드 재현 가능. 외부 유료 LLM/비결정론적 클라우드 호출을 필수로 하지 않는다.
- 새로운 기술·문명 단계·작물·집·법·사냥·교역 성공을 강제로 스폰하지 않는다. 모든 새 방법은 재료·위치·시간·에너지·물리적 행동·결과 검증을 거친다.
- NPC가 GPT 수준의 범용 언어·추론 능력을 갖췄다고 주장하려면 별도의 실측 평가가 필요하다. 현재의 C++ 목표 생성기를 GPT라고 부르지 않는다.

## 구현 단계와 완료 판정

### B4c — 경험 결과를 개인의 다음 선택으로 전달
- 이미 존재하는 개인 목표/안전한 사회적 상대 선택(B4a/B4b)에 후속 루프를 만든다.
- **B4c-1 (이 PR)**: 실제 완료한 Approach/Repair 후 *본인의 valence 변화*만 직접 관찰·기억·믿음화. 소규모 tie-break로 다음 사회적 대상 선택에 전달. 타인의 비공개 trust를 안다고 가정하지 않는다. 모든 memory/belief는 기존 snapshot에 포함; AI가 직접 외부에서 기록하지 못한다.
- **B4c-2 (후속)**: 발행한 목표 ID, 현재 상태 지문, 실제 물리 action token, 완료/실패/중단, 객관적 검사 및 주민 주관의 학습 기록을 인과적으로 결속. 저장 중 재개·순서 변경·재시도로 중복 성공/실패가 생기지 않도록 명시적 persistent provenance.
- **B4c-3 (후속)**: 실제 식량/물/수면/위생·자원·사회 성과를 goal predicate로 관찰 가능한 범위에서만 평가. 행동 완료 != 원래 목표 달성.
- **성공 조건**: 특정 성공/실패를 주입한 동일 물리 상태 A/B replay에서 다음 자율 선택이 합리적으로 달라지고, 생존 긴급 보호, 자원 보존, snapshot replay가 모두 통과한다.

### B5 — 가설·대안 계획과 안전한 실험
- 기억과 직접 목격/전언/추론에서 경쟁 가설을 구성; 특정 목표 상태를 이루는 서로 다른 행동 시퀀스를 Core affordance로 조합. 고정 기술 트리 해금과 구별.
- 실패해도 안전한 실험 예산(시간·자원·위험)을 Core가 허가. 없는 물건·공간·과정은 실험 불가 또는 불확실로 표기.
- 실패, 예상외 결과, 조건 변화, 타인 모방을 구분하는 반증·재시도 메커니즘.
- **성공 조건**: 서로 다른 시드/개인에서 실행한 대안의 성공·실패에 따라 계획이 변화하고 허위 성공이나 자원 증식이 없다.

### B6 — 사회적 집단지성
- 개인이 얻은 관찰을 말·보여주기·가르치기·거래로 제한적으로 전파. 신뢰도와 출처, 잘못된 지식, 독립 재검증 모두 유지.
- 관계·협력·역할 분화·갈등·규범은 결과 기반으로 변화. 결혼/임신/육아/교육/세대 전승과 연결.
- **성공 조건**: 공유가 없으면 지역마다 다른 믿음, 교류 후 전승, 오정보 전달의 교정, 실제 출산·성장 이후 기술 기억 차이 관측.

### B7 — 자연·지구와 함께하는 문명 창발
- 지구 지역별 위경도·태양시뿐 아니라 기온/강수/토양/수계/서식지 및 독립 야생동물 Core를 실제 World·생계·관찰과 연결.
- 주민 집단 A/B가 독립 지역에 존재하며 정직한 이동·교역·지식 전파·이주를 수행. 구체 지구 확대하면 같은 Core 세계의 생활 장면으로 진입.
- 작물·수리·시설·기술은 보유 자원과 행동 결과에서 생기며, 발전되지 않는 지역도 허용.
- **성공 조건**: 같은 규칙·다른 지리/경험에서 서로 다른 장기 생존/문화/기술 경로가 재현되고, 자원/물리 위반 없이 교역과 세대 전환이 일어난다.

## 필수 상시 검증/품질 게이트

- exact-head Core tests / preflight / WASM / Web build, snapshot binary roundtrip, deterministic checksum.
- 100/365/1000일 다중 seed와 중간 저장·복원 비교; 장기에는 3000일 이상 샘플.
- 생존 행동 vs 탐구·사회 행동 예산, Goal attempted/achieved/blocked, 목표 오귀속률, 반복 실패, 자원 순환, 질병/출산/세대교체, 지구-지역/동물 상호작용 인과 추적.
- CI 통과는 완성 증명 아님: 실제 Android GPU, 터치, 애니메이션, Web FPS와 UX를 별도로 검증.

## 이번 PR의 실제 한계

B4c-1은 내 감정만 학습한다. **관계 목표(상대 trust)가 달성되었다고 기록하지 않으며, 범용 계획·새 도구 발명·자율 문화 창발이나 GPT급 언어 추론을 구현한 것이 아니다.** 대규모 추론 모델 없이도 관찰 가능한 자율성을 먼저 실제로 쌓는다.
