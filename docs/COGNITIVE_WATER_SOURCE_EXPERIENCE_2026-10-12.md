# 자율 학습 AI — 직접 경험한 수원 선택 (2026-10-12)

부모 작업 [#664](https://github.com/sjLim91/lifelens-ue/pull/664)의 행동 결과 기록을 **방법·장소 선택**으로 확장한다. 설계 원칙·Health/Needs/세계 물리·사회 및 Core authority 변경 없음.

- 기존 `EnvironmentalExposure.h`는 실제 주민이 겪은 지역 오염을 직접 경험 기억으로 저장. 방문하지 않은 수원의 품질은 AI가 임의로 알 수 없다.
- 새 `WaterSourceExperience.h`: 주민별 **직접 목격한** 오염 기억과 당시의 위치에 따라 유효한 자연 수원 중 하나를 결정론적으로 선택. 없는 물·막힌 노드를 생성하지 않는다.
- 미경험 수원은 중립, 과거의 직접 경험은 `effectiveConfidence`에 따라 서서히 약해짐. 식수 위험 자체를 제거하지 않고, 3칸 이내 우회 가중치만 적용. 실제 경로·섭취·병원체·오염은 기존 Core가 처리한다.
- 같은 세계에 살아도 경험이 다르면 다른 수원으로 이동할 수 있다. 확신할 수 없는 질병의 원인을 특정 물가로 억지 귀속하지 않는다.
- 새 test_water_source_experience: 직접 경험/미경험/소문/오래된 경험/단일 수원/긴 우회/결정론 동점/수원 부재. Core 전체 테스트와 두 seed 장기 감사 필수.

**주의:** 단일 메모리로 새 자원을 발명하거나 물이 필요 없다고 행동하지 않는다. #664의 기존 조건부 경험 기록과 달리, 이 PR의 실제 선택 변화는 거주자 자신의 공간 기억에서만 발생한다. 설계규칙 조정 없이 새로운 행동 조합을 가능하게 만드는 첫 단계다.
