## F2-f 범위

1. `fieldForestDisplayClusters`: 기존 **매 청크 동일한 북서/남동 중심 두 점**을 제거한다. 씨드와 절대 월드 좌표를 공유하는 다중 스케일의 연속 분포값으로 실제 `forestCoverage01` 허용량의 나무 시각 후보를 선택한다. 식생은 장식이며 실제 나무 수·충돌·서식지 리소스를 생성하지 않는다.
2. 자연 SVG 제한적 다양화: 기존 승인된 pine/cedar/oak/bush를 고정 Core 좌표 기반으로 약간 좌우 반전·색조 보정만 한다. 기존 색감·개체 의미를 유지한다. 이미지 파일 자체는 여전히 단순하므로 아트 리워크 완료라고 주장하지 않는다.
3. `fieldGroundDetailMarks`: 실제 Core grass/forest/rock 피복에 따른 작은 잔디·토양 표시 밀도를 근거리에서 보강하고, 넓은 화면에선 그리기 예산을 낮춰 모바일 CPU 사용량을 제한한다.
4. 잠자는 주민의 벡터 뼈대는 여전히 실제 Core 위치에서만 그림을 그리되, 기존 전신 회전 피벗이 몸통 전체를 좌측으로 밀어 보이던 오류를 보정한다. **실제 Core 침구 사용 근거 없이 주변 침구에 주민을 스냅하지 않는다.** 실제 잠자리 선택/운반 등은 별도의 Core/AI 진단 대상이다.
