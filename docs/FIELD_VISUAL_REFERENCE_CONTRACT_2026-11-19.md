# LIFELENS Field Visual Reference Contract — CANONICAL (2026-11-19)

## 결정
사용자가 제공한 모바일 게임 화면은 **시각적 품질과 2D 필드 아트 표현 방식의 레퍼런스**일 뿐, 해당 게임의 세계관·퀘스트·몬스터·장소 콘텐츠를 라이프렌즈로 이식하라는 요청이 아니다.

목표는 LifeLensCore가 실제 관측한 **자연 지형·식생·수계·주민·야생동물·시설**을 읽기 쉽고 통일감 있는, 풍부한 모바일 게임형 필드 화면으로 표현하는 것이다. "2D/2.5D"라는 기술 라벨과 임의 카메라 회전보다 **실제 모바일 화면에서 자연스럽고 완결된 공간**을 우선한다.

## 반드시 참고할 표현 방법
1. **지면:** 반복되는 거대한 마름모 타일이나 단색 평면이 아니라, Core biome/coverage/고도에 종속된 연속적인 자연색·미세 지면 텍스처·자연스러운 경계를 사용한다.
2. **지형 기복:** 실제 Core elevation sample에서만 절벽·바위 사면·능선의 높낮이를 표현하고, 평평한 구역에 임의 절벽을 만들지 않는다.
3. **식생:** 실제 forest/shrub/grass/wetland coverage를 바탕으로 나무·풀·덤불을 군집으로 시각화한다. 화면상 식생 스프라이트의 배치/밀도는 장식일 뿐 Core 생태 수량을 변경하지 않는다. 이웃 청크도 끊김 없이 연결된 느낌이어야 한다.
4. **수계:** Core가 관측한 하천·호수·바다·수변에만 자연스러운 물색과 경계/흐름을 표현한다. 보기 좋다는 이유로 물길/폭포를 가짜로 생성하지 않는다. 폭포는 실제 낙차 및 수계 근거가 있을 때만 후속 단계에서 다룬다.
5. **오브젝트:** 나무·바위·건물·주민·동물을 같은 화풍/원근·일관된 비율·지면 접촉 그림자·깊이 정렬로 표현한다. 생활 시설을 다른 종류의 건축물로 보이게 하거나, 주민을 엉뚱한 잠자리로 이동시키지 않는다.
6. **모바일 관찰:** 실제 Core 주민 행동을 관찰할 수 있도록 시야/축척을 조절하고 HUD는 필요한 만큼만 노출한다. 지나치게 어두운 밤, 쌓인 큰 일러스트로 가려지는 주민은 방지한다.

## 절대 혼동 금지
- 참고 이미지의 게임 캐릭터, 몬스터, 레벨/전투/퀘스트/던전/보스, 특정 특수구역 테마를 라이프렌즈 콘텐츠로 가져오지 않는다.
- 자연환경은 기존 Core가 확인한 biome/hydrology/ecology를 따른다. **이미지에 등장했다는 이유만으로 거미 구역, 마법 지역, 몬스터 지역 등은 추가하지 않는다.**
- 레퍼런스의 특정 작품을 그대로 복제하는 것이 아니라 **조화로운 표현 기법**만 참고한다.
- 월드 생성/시드/AI/시설/자원/개체 수/동물종/주민 위치·행동·시대·Save truth에는 아무 변경도 하지 않는다.
- CSS/카메라 회전/스프라이트 스케일만 바꾸고 "그래픽 목표 달성"이라고 주장하지 않는다. 시각 QA는 실제 출력 기준이며 실기기 검증은 별도 승인 전까지 제외한다.

## 단계 및 인수
- **F2-d (현재):** 핵심 의미 바로잡기, 모바일 필드의 강제 45도 마름모 투영 제거, Core 기반 지면 표현과 식생 군집 보강, 기존 선택/동작/수면/날씨 회귀 테스트.
- **후속 표현 작업 (별도 승인/마일스톤):** 동일 화풍의 환경/시설/주민 아트 제작과 실제 Core 수계·기복에 따른 벽면/낙차 시각화, 장면 스크린샷 비교 검증.
- 완결 선언에는 실제 화면 비교가 필요하다. 자동화 통과는 화면의 미적 완성도를 증명하지 않는다.

## 우선순위
지속적 결정: 사용자 첨부 레퍼런스 **= 아트 디렉션 참고, 콘텐츠 도입 제안 아님**. 새 개발/AI 에이전트는 이를 임의로 해석하지 않는다.
