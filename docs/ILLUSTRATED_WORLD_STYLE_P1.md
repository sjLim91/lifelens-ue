# LifeLens P1 — 실제 관찰 월드의 일러스트 환경 스타일 실험

상태: P1 실험 코드 / 기존 기본 스타일 유지
기준: main 4cadf25b (#1040, P0 지역 지도)

## 의사결정

- **기존 Three.js 지형·주민·수계·생태·시설·카메라를 그대로 유지**한다.
- 실험은 지면의 색채, 풀·관목·바위의 색상과 바위의 면 음영, 나무 잎과 수피의 면 음영만 바꾼다.
- 사용자 제공 게임의 아트 방향에서 **초록색 지면·다양한 숲·명확한 암석 대비·일관된 색채**를 차용한다. 해당 게임의 아트 에셋·코드·이미지는 사용하지 않는다.
- 신규 2D 가짜 자원/하천/정착지나 새 NPC는 생성하지 않는다. Core 행동, Core 수량, 식생 위치·종류, 3D 리그/모션, 셰이더 기상 효과 및 저장은 변경하지 않는다.
- 모바일의 기존 GPU 없는 Canvas 호환 경로는 그대로 둔다. P1 스타일 실험은 Three.js에서만 표시한다.
- 기존 스타일은 URL에 별도 키가 없는 상태로 유지한다. P1 실험은 `?world-style=illustrated`를 선택했을 때만 켜진다.

## 사용자 비교 절차

1. 게시된 라이프렌즈에서 기존 세계를 열거나 Seed를 입력하여 생성한다.
2. **환경: 그림풍 보기** 버튼을 누른다. 같은 저장 세계를 다시 여는 페이지 재로드 후 새 팔레트가 적용된다.
3. 숲·초원·바위가 보이는 지역에서 카메라를 이동하고 주민·시설·하천과 겹치지 않는지 확인한다.
4. **환경: 기존 보기** 버튼으로 원래 표현을 복원한다.
5. 두 환경 모두 동일한 실제 Core의 주민·지형·정착지 데이터를 표시한다. 비교 중 Core 시간이 진행될 수 있으므로 한 화면에 나란히 동일 프레임을 보여 주는 기능은 아직 없다.
6. Android 앱 내 GPU 없는 Canvas 모드에서는 이 Three.js 스타일을 강제 활성화하지 않는다.

## 검증 및 인수 기준

- TypeScript 타입 검사, Web shared regression, 프로덕션 Vite 빌드, Preflight.
- 순수 스타일 URI 테스트: 기본 = classic, 명시적 opt-in만 illustrated, Seed/추가 URL 파라미터 유지.
- 3D 지형 테스트: 기본/실험의 정점 위치·법선·UV·삼각형 인덱스 **완전히 동일**, 정점 색상만 다름; 입력 TerrainWindow 불변.
- 생존/자원/AI/지형·수계/Core 저장 변경 없음 (Web presentation만 변경).
- 모바일 Canvas 모드에 새 WebGL 컨텍스트가 생성되지 않음.
- 확인하지 않은 실기기 FPS/열/장시간 메모리 향상을 주장하지 않음.
